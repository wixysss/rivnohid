# Прошивка ESP32: живі дані акселерометра

Пристрій читає MPU6050 (200 Гц) і кожні 100 мс відправляє пакет JSON через MQTT
(`broker.hivemq.com`, топік `rivnohid/rv7f3k/live`). Сторінка `/live` сайту
підписується на той самий топік через WebSocket і малює графіки наживо.

## Як прошити

1. Скопіюй `secrets.example.h` у `secrets.h` і впиши Wi-Fi. Мережа має бути **2.4 ГГц**.
2. Arduino IDE → Library Manager: встанови **PubSubClient** і **TinyGPSPlus**.
3. Board: **ESP32 Dev Module**, порт CP210x, Upload.
4. Після старту 2 секунди не рухай пристрій: він калібрує напрям гравітації.

## Пакет

```json
{"seq":12,"t":51230,"hz":200,"a":[12,-30,...],"rms":0.081,"pk":0.42,
 "bump":0,"mark":0,"bat":3.92,"lat":50.25,"lon":28.65,"spd":4.1,"sat":7}
```

`a`: 20 відліків вертикального струсу в мілі-g. `bump`: пік понад 0.6 g. `mark`: натиснута кнопка 2.

## Світлодіод

Жовтий: підключення. Зелений: дані йдуть. Синій спалах: яма. Червоне блимання: датчик не знайдено.

## Відомі проблеми

Якщо з увімкненим Wi-Fi значення стрибають або MPU6050 «скидає налаштування», це просідання
живлення: живи GY-521 від 5 В (VIN), а не від 3V3, і постав 100 мкФ між 3V3 і GND.
